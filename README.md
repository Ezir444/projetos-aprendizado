Projetos independente para aprendizando sobre biblioteca tkinter

            #O que é projeto calculadora de Gastos?
Objetivo é criar uma interface com tkinter em que é possivel especificar o tipo de gasto de uma pessoa, por exemplo aluguel,transporte e etc... Armazenar a hora que foi registrado e fazer um somatório e posteriormente ser possivel subtração do que estiver registrado.
Ainda esta no começo mas tem bastante coisas que pretendo adicionar, por exemplo.

1.Possibilidade de somar o que estiver armazenado e também retirar um valor já registrado
2.Uma outra janela em que é possivel informar dinheiro a receber, informando o nome,hora e tipo de divida exp: Às 20:00 foi emprestado 50 reais a João para pagar um pizza.
3.Estilizar as janelas com objetivo de ser agradavel visualmente e intuitivas.
4.Gerar um relatório onde é possivel ver todo o dinheiro gasto em um mês,a receber e quanto já foi investido.
etc....
